## 怎么回交

1. 填写本包根目录的 `回交记录.md`，未核实写“未核实”，关门、不供应、无法通行等照实记录。
2. 照片、菜单、公告、通行记录等放入根目录 `回交证据/`，在记录里写对应文件名。没有照片时也可留下电话答复的实际时间、对象、内容与适用日期，但不得冒充现场观察。
3. 将整个文件夹压缩回交。熟悉JSON的队员也可填写 `data/route-acceptance/field-review-template-20261025.json`，不强制使用JSON。

请记录核验人、核验方法、真实时间和有效日期。实际采证日期如有调整，明确写出；不能直接把10月24日旧营业规则换日期。路线未实走的部分保留缺口。
