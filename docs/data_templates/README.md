# 队员采集模板（路演前）

两份表都用 Excel 打开、填写后另存为 CSV（UTF-8）交回。系统导入时逐行核对，填错的行会被退回并说明原因，不会写进库。

## 1. 演出场次 `show_sessions.csv`

只采集**路演那几天（10-31 至 11-02）**每一场的真实时刻，来源必须是当期公布的场次表（景区官网、公众号、现场公告牌照片等）。

- 一场演出一行；同一节目一天演三场就写三行。
- **节目名称**照抄 `show_program_reference.csv` 里的写法，系统按它匹配已有节目。参考表里没有的节目，名称照公告写，导入时会被单独列出来，由 Claude 处理。
- 演出日期写 `2026-11-01` 这种格式，时刻写 `10:00` 这种 24 小时制。结束时刻、停止入场不知道就空着，不要估。
- 第一行是示例，导入时会跳过，不要删除。
- **不要**把参考表里的"公告时刻"直接抄成某一天的场次。那是公告上的通用时刻，不代表那天一定演。

## 2. 餐厅口味与招牌菜 `restaurant_taste.csv`

店名已经填好（系统里现有的 32 家），请补全后面几列。

- 口味标签、招牌菜可以写多个，用顿号（、）分隔。
- 辣度只写"不辣""微辣""辣"三种之一。
- 来源可以是大众点评/美团截图、菜单照片或实地记录。写清来源，截图文件名与表里一致，和表一起交回。
- 不确定的格子就空着。系统会对游客说"暂无资料"，不会猜。

## 3. 节目参考表 `show_program_reference.csv`

只用来查节目名称，不用填写。其中 154 个节目的景区一栏为空，原因是原始资料里没有写景区，不是遗漏。
