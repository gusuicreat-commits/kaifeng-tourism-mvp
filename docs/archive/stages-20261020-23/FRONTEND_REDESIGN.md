## 从原页面到新体验

原先首页以图片陈列为主，助手、单景区路线与城市安排的入口分散；收藏与行程未形成共同入口，菜品容易被误当作餐饮目的地。现在主导航统一为：

| 主入口 | 页面职责 |
| --- | --- |
| 发现 `/` | 有行程时先看下一站；无行程时展示主题图与创建入口；搜索、分类、横滑景点和美食 |
| 行程 `/city-trip/:id?` | 保存日期和地点、时间线/地图、下一站、修改比较与确认、游玩进度 |
| 地图 `/guide` | 城市地点查询、当前目的地；切换万岁山/清明上河园示意导览 |
| 我的 `/me` | 本次收藏、服务端保存行程、既有隐私/导出/删除入口 |

小汴梁保留原形象并跨页悬浮，不占主导航。旧 `/plan`、`/crowds`、景区详情、记录管理和单景区结果仍有兼容入口。旧城市维护表单保留在 `/city-trip/manage/:id?`。

## 状态与真实后端

首页、行程、城市地图、详情操作使用同一 `journey.ts` 响应式对象。城市安排调用现有 `/api/city/v1/facts`、`/trips/current`、`/trips`、单行程读写、`/changes`、`/confirm`，复用会话属主、版本和幂等机制。刷新以服务端安排为准；收藏与未匹配候选只保留在浏览器会话存储，最长24小时，不承诺跨设备恢复。

2026-10-21收尾只读检查：运行库 `city_facts` 为 **0条**。因此运行页面没有可以认证的城市商家供应关系和全程交通。隔离测试使用 `backend/tests/fixtures/city_facts.json`，所有地点带 `[测试]`，临时数据库在测试结束后销毁；没有把该夹具导入运行库。

## 地图技术与Mock

城市地图复用 `ExternalMap` 的高德能力及外部搜索降级；未验证高德在两个景区的完整园内覆盖。景区使用现有SVG示意底图与独立点位/路网，支持点击、拖拽、缩放和沿图最短路。缺边不补直线，GPS不投到未配准坐标。场次/估时演示单独标注，默认无模拟热力和模拟演出。

地图没有替换成参考图里的插画，不将未配准图片当作真实导航。后续正式接入需要：经过核验的城市地点/入口、营业与进出园规则、菜品供应证据、目标日期完整场次、经核验园内有向路网与城市交通资料；然后将独立引擎的正式路线/预览/重规划接口接入新时间线和地图，并完成现场走查。

2026-10-21已按用户补充的正确图片替换炒凉粉，首页卡片与详情页共用该资源；花生糕及其他图片保留。
