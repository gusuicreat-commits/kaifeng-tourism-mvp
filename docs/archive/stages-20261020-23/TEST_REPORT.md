## 核心断言

- 搜索可过滤景区，没有结果时有空状态。
- 两景区的8节点图连通，所有位置和道路均带演示标记；没有内部地图的景区不返回伪造路网。
- 距离模式的两点路径长度等于独立NetworkX最短路径基准；绘制的路线坐标与实际经过节点一致。
- 1小时时间预算内，演出兴趣与美食兴趣生成不同推荐；必去点得到保留，步速改变耗时。时间不足、点位无效返回422。
- 修改模拟拥挤指数能改变避拥挤路径；通过真实CSV导入/更新非模拟观测，也会改变符合时段的避拥挤路径。距离最短路径不被拥挤指数改变。
- 无非模拟数据时当前观测、估计都未知；模拟历史永不成为当前客流；过期、汇总和未来记录不能假装为当前瞬时观测。
- 没有可靠客流时明确退回普通规划，结果与未启用避拥挤的普通兴趣路线一致；同日同时段的合格来源遵循官方、实地、第三方优先级。
- 少于3个采样日不产生历史估计。仅人数、无容量时不编造拥挤指数；日汇总不推断时段规律。
- CSV有错误整批不写入，重复导入更新原记录；时区归一化，来源、可信度、模拟标记保留；文件大小、数据范围、时间和点位校验生效。
- 浏览器实际覆盖点位点击、地图缩放、策略重算、结果刷新、CSV成功/失败、参考时段切换、数据集分离、网络失败重试、320和390px无横向溢出。
- 已查看桌面首页、桌面客流页、手机路线页的实际截图，未发现阻塞核心操作的渲染问题。
