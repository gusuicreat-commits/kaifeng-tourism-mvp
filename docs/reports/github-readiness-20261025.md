# GitHub 提交前检查

## 已处理的问题

- 清理安装依赖现在包含 `psycopg`，默认检查命令使用 `python -m pytest`，不依赖当前终端的 `PYTHONPATH`。
- `/api/crowds/import` 与景区节目管理接口统一要求服务端管理员密钥和审核人标识。
- 景区节目查询会区分 `approved_schedule`、`review_required`、`stale_source`、`unavailable`；未审核节目不会进入求解器。
- 历史参考资料不再依赖仓库外的本机目录，仓库内只保留带来源摘要的未核验结构化摘录。
- 新增 GitHub Actions：安装锁定依赖、启动独立 PostgreSQL、运行后端/采集器/浏览器测试和前端构建。
- `/pitch` 路演页面使用本地资源，构建时生成，不调用业务 API 或外部资源；交互示例只改页面内演示状态。

## 提交前人工动作

- 当前 `.env` 仍有本机真实密钥格式，虽然没有进入 Git 历史，也没有被提交；提交 GitHub 前应在对应供应商后台作废并重新生成，之后只写入部署平台或本机 `.env`。
- 仓库目前没有声明开源许可证；如果公开仓库，提交者需要选择适合团队的许可证，不能由代码自动推断。
