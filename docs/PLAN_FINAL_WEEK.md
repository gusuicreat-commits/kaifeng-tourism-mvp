## 演示脚本（彩排和录屏都按这个走）

1. 首页 → 进入开封府详情 → 加入素材篮；同样加入第一楼、鼓楼夜市。
2. 打开小汴梁："今晚五点半从开封府出发，想吃灌汤包，十点前回来，走路就行。"
3. 查看规划预览：顺序、每段步行时间、哪些信息"待确认"。→ 确认。
4. 行程页 + 地图展示路线。
5. 途中修改："九点前回来" → 时间不够时小汴梁说明哪一站没排进，预览里对比新旧安排 → 确认。

讲解重点：AI 负责听懂需求，路线由算法计算，重要修改要游客确认才生效；资料不全时如实提示，而不是编造。
