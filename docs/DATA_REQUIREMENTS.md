# 当前需要的数据

依据：[用户提供的数据清单](reference/bianliang_data_guide_20261021.pdf)。目标是让游客完成“景点、演出、美食、交通、途中调整”的整段行程。

- 地点：名称、真实入口、坐标系、开放时间、门票和再次入园规则。
- 演出：节目与具体场次分开；场次要有日期、开始与结束、舞台、取消或变动状态。
- 美食：菜品、真实商家、商家确实供应该菜的证据；还需位置、营业和用餐时间。
- 交通：规划时按需查询高德估时，计入出园、城市转场、进园及缓冲；不自建全市路网。
- 园内道路：先核实主入口、舞台和必要主路。未核实只能示意，不能称为正式导航。
- 行程：保留必去项、已完成项、当前起点和版本；途中修改只重算剩余部分。
- 每条重要事实保留来源、核实时间、有效期和使用权限。未知留空，不用猜测补齐。

首批建议：8–12个城市目的地、10–20种菜品、15–25家商家、至少25条核实的供应关系。数量及两周安排是建议，不是已完成或工期承诺。实时客流暂不阻塞首版。

验收看四件事：跨景区一日游、两场演出衔接、演出间吃饭、途中改计划。旧采集包继续作候选资料，旧节目单不能换日复用。缺数据就说明限制，不能承诺一定走得通或赶得上。

数据现状见[DATA_SOURCES.md](DATA_SOURCES.md)，开发范围见[PRD.md](PRD.md)。

2026-10-21 已完成事实入口与城市安排存储：采集者可先按[空模板与导入说明](CITY_STORAGE_AND_FACTS.md)整理并校验，暂缺数据保留候选/未知状态。运行库尚无正式城市事实；接口建好不表示上述数据已经采齐或路线可执行。
